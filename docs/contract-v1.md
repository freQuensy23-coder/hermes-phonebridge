# PhoneBridge contract v1 (supersedes implementation-plan.md)

Accepted: Samsung/Pixel and modern Android, server-generated one-time QR scanned in app, outbound persistent background connection to Hermes host, CLI and skill, GitHub CI/CD. No own alarm/timer subsystem. Use existing clocks, native Android APIs and explicit permissioned UI adapters. Normal users do not require root/ADB/Shizuku. UI actions require an unlocked phone; do not claim silent universal control. Guided one-time Android permissions. Version0.1.0. Python3.11+, Kotlin JDK17, minSDK31 target/compile35. No code comments/docstrings. All tests/linters/scanners run ONLY in automated GitHub CI, never manually here. Main via PR. Parent owns root/docs/.github/deploy; server implementer owns server/; Android owns android/; CLI owns cli/skills/. Children no git commits/pushes and no other directory changes.

## Phone features

Native QR scanner ZXing, onboarding permissions, status/stop/disconnect. Foreground specialUse connection service with visible ongoing notification, boot/package-replaced restore, network reconnect, no permanent wakelock. Force-stop/OEM battery restrictions documented. Android token excluded backups; secure listener exported only with Android signature binding permission. Actual Android handlers: device.info/capabilities, notifications.list/dismiss/reply/action (exact key/action), apps.list/open, audio.get/set, contacts.list, calendar.list/create/delete, clipboard.get/set, location.get(last-known source+age), torch.set, calls.dial, sms.list/send; screen.tree/screenshot/tap/swipe/input/global via optional Accessibility. SMS/reply/dial/calendar delete user-intent restricted via skill.

Clocks: clock.providers -> {providers:[{package,name,version,adapter,native_actions:[...],ui_actions:[...],screen_required:bool}]}; clock.alarms.create {hour,minute,label?,days?:[1..7 Monday..Sunday],package?}, dismiss {label?,hour?,minute?,package?}, snooze {minutes?,package?}, show {package?}; clock.timers.create {seconds:1..86400,label?,package?}, dismiss {uri?,package?}, show {package?}. Typed Android AlarmClock intents and explicit known resolved package. Translate days to Java Calendar numbering. Repeating dismiss skips next occurrence; missing timer URI dismisses expired only. Do not claim list/disable/delete via standard intents.

Implement clock.alarms.list/enable/disable/delete and clock.timers.list/cancel/pause/resume only with concrete supported UI selector+read-back.
